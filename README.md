# 🚀 DuoPy — Совместное программирование на Python через интернет

**DuoPy** — современное приложение для парного программирования (Pair Programming) на Python. Оно создано специально для того, чтобы разработчики могли работать вместе, **находясь в разных странах, городах и сетях**, без необходимости настраивать роутеры, открывать порты или настраивать VPN.

---

## 🌍 Как это работает между разными странами и сетями?

Когда два человека находятся в разных странах (например, Россия и Германия) или подключены через домашний Wi-Fi / мобильный интернет (за NAT):

1. **Создатель** нажимает кнопку **«🌐 Создать комнату»**:
   - Приложение генерирует уникальный короткий код комнаты (например, `DUO-8419`).
   - Нажимает кнопку **«Скопировать код»** и отправляет его напарнику в Telegram, WhatsApp, Discord или почту.
2. **Второй участник** (в любой точке мира) открывает DuoPy:
   - Нажимает **«🔗 Войти по коду»**, вставляет `DUO-8419` и нажимает **«Войти»**.
3. **Мгновенное соединение!**:
   - Связь устанавливается через защищенный облачный шлюз (Cloud Relay).
   - Все изменения кода, движение курсоров, запуск скрипта и вывод ошибок синхронизируются в реальном времени с пингом ~50–100 мс.
   - **Не требуются** белый IP, проброс портов (Port Forwarding), Hamachi или сложная сетевая настройка.

> 💡 Для работы оффлайн или в одной закрытой сети также доступен классический режим **«🏠 LAN / IP»**.

## ✨ Возможности

- ⚡ **Синхронизация в реальном времени**: непрерывный обмен текстом программы без задержек.
- 🎯 **Курсор напарника**: вы видите, на какой строке и каком символе находится собеседник (с бейджем имени и уникальным цветом).
- 🎨 **Подсветка синтаксиса Python**: в стиле VS Code Dark (функции, типы, классы, строки, ключевые слова, декораторы).
- ▶️ **Запуск кода (F5) и удаленный терминал**:
  - Запуск скрипта в изолированном асинхронном процессе (GUI не зависает).
  - Стриминг вывода `stdout` и `stderr` в интерактивный терминал.
  - Синхронный просмотр выполнения обоими участниками.
  - Принудительная остановка процесса (⏹ **Shift+F5**).
- 🔍 **Авто-детекция и подсветка ошибок**:
  - При возникновении исключения (Traceback) приложение автоматически определяет проблемную строку.
  - В редакторе эта строка подсвечивается **красным маркером**, а курсор перемещается к ней.
- 💬 **Встроенный чат**: текстовое общение прямо в окне программы.
- 📁 **Проводник проекта (Папка с файлами)**:
  - Панель файлов слева: просмотр структуры проекта в виде дерева.
  - Открытие файлов кликом мыши (содержимое мгновенно транслируется напарнику).
  - Быстрое создание новых файлов (`➕`), удаление, переименование и смена рабочей папки (`📁 Папка`).
- ⌨️ **Быстрое комментирование (Ctrl + /)**:
  - Выделите блок кода (или поставьте курсор на строку) и нажмите **Ctrl + /** — строки мгновенно закомментируются или раскомментируются.
- 🛠 **Комфортный редактор**: номера строк, Tab = 4 пробела, Shift+Tab = unindent, авто-отступ после `:`, открытие (`Ctrl+O`) и сохранение (`Ctrl+S`).

## 📦 Установка

Требуется Python 3.10+:

```bash
cd d:\Project\DuoPy
pip install -r requirements.txt
```

*(Зависимости: `PyQt6`, `paho-mqtt`)*

---

## 🎮 Запуск

### Способ 1: Готовый EXE файл (Без установки Python)
Скачайте **`DuoPy.exe`** со страницы [Releases](https://github.com/famouSSeX/DuoPy/releases/latest) и запустите двойным кликом — установка не требуется. Приложение само предложит обновиться, когда выйдет новая версия.

### Способ 2: Запуск из исходного кода
```bash
python run.py
```
*(или двойным кликом по `start_duopy.bat`)*

### Подключение через интернет (разные страны / сети):
1. **Первый участник**: нажимает **«🌐 Создать комнату»** ➔ копирует код `DUO-XXXX` и отправляет собеседнику.
2. **Второй участник**: нажимает **«🔗 Войти по коду»** ➔ вводит код `DUO-XXXX` ➔ нажимает «Войти».

### Локальное подключение (LAN):
- Нажмите **«🏠 LAN / IP»** ➔ выберите «Создать сервер» или «Подключиться к IP».

## 🔒 Безопасность совместной сессии

DuoPy рассчитан на работу с доверенным напарником, но базовые проверки всё же есть:

- **Пути от напарника** (`GET_FILE`, `SAVE_FILE`, `CREATE_FILE`, `DELETE_FILE`) разрешаются только внутри папки проекта: абсолютные пути, `..` и соседние каталоги с похожим именем отклоняются.
- **Удалённый запуск кода требует подтверждения**: код напарника не выполняется на вашей машине, пока вы не согласитесь в диалоге.
- **Облачные комнаты** идут через публичные MQTT-брокеры: сначала пробуется шифрованное соединение (TLS, порт 8883), при недоступности — обычное (1883), о чём приложение предупреждает в статус-баре. Код комнаты (`DUO-XXXX`, 4 цифры) не является средством аутентификации, поэтому не публикуйте его и не открывайте доступ к проекту с ценными данными.
- **Входящие правки не затирают набор**: если напарник меняет строку, которую вы прямо сейчас печатаете, его правка применяется сразу после короткой паузы (0,9 с), а не затирает набираемый текст.

## ⚡ Скорость синхронизации

Правки передаются **только изменённым фрагментом**, а не файлом целиком, и без подтверждения доставки (QoS 0), потому что подтверждение добавляет к каждому нажатию полный круг задержки до брокера. Крупные сообщения (например, первичная синхронизация проекта) сжимаются — исходный код сжимается в 6–7 раз.

Что это даёт на канале «через интернет» (публичный брокер, круг ~200 мс):

| Ситуация | Было | Стало |
|---|---|---|
| Набор в файле 100 КБ | ~2000 мс на правку | ~140 мс |
| Трафик на 17 символов набора | ~1,4 МБ | ~5–180 КБ |
| Правка в файле 20 КБ | ~735 мс | ~140 мс |

Так как доставка фрагментов не подтверждается, потеря пакета обнаруживается по номеру правки: стороны сразу выравниваются полной синхронизацией, поэтому расхождение не остаётся незамеченным. Если печатать одновременно в одном и том же месте, конфликт решается последней записью — полноценное слияние одновременных правок требует другого протокола (OT/CRDT).

## 📶 Скорость соединения

DuoPy показывает качество связи с напарником прямо в статус-баре:

- **Задержка (пинг)** — метка времени уходит напарнику и возвращается, измеряется круговое время (RTT). Обновляется каждые 2 секунды.
- **Скорость передачи текста** — сколько килобайт в секунду реально передаётся в каждую сторону; служебные пакеты в статистику не входят.
- **Цветовой индикатор**: 🟢 до 150 мс, 🟡 до 400 мс, 🔴 выше. На очень быстром канале показывается «<1 мс».
- **Подробные замеры** — по клику на индикатор: текущая, средняя и худшая задержка, скорости приёма и отправки, пиковая скорость, объём за сессию и график истории задержек.

Задержка видна и в списке участников — рядом с именем напарника.

## ⬆️ Автообновление

Приложение само проверяет свежую версию на [GitHub Releases](https://github.com/famouSSeX/DuoPy/releases) — тихо, через пару секунд после запуска. Если вышла версия новее установленной, DuoPy предложит обновиться:

1. Новый `DuoPy.exe` скачивается в `%LOCALAPPDATA%\DuoPy\updates` (папку приложения трогать не нужно).
2. При согласии запускается установщик: он ждёт закрытия DuoPy, подменяет исполняемый файл и запускает новую версию.
3. Журнал установки: `%LOCALAPPDATA%\DuoPy\updates\update.log`.

Проверить обновление вручную можно кнопкой **🔄 vX.Y.Z** на панели инструментов.

### Как выпустить новую версию

1. Поднимите номер версии в двух местах: `APP_VERSION` в `duopy/updater.py` и `__version__` в `duopy/__init__.py`, а также `filevers`/`prodvers` в `file_version_info.txt`.
2. Соберите EXE: `pyinstaller --noconfirm --clean DuoPy.spec`.
3. Создайте релиз с тегом `vX.Y.Z` (например `v1.2.1`) и **приложите к нему `dist/DuoPy.exe`** — именно этот файл скачивают клиенты. Если файла в релизе нет, приложение просто предложит открыть страницу релиза.
